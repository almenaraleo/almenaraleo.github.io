# almenaraleo.github.io

Portfólio de Leonardo Faria Almenara — design da informação, visualização de dados, design editorial e sistemas de identidade visual.

- `/` — página inicial
- `/ministerio-da-saude/` — Design no Ministério da Saúde 2021–2026 (SAPS e Desid)

## Estrutura de `ministerio-da-saude/`

- `index.html` — página do portfólio
- `data/projetos.csv`, `data/produtos.csv`, `data/indicadores.csv` — conteúdo editável (textos, anos, contagens)
- `data/galeria_*.json` — legendas e ordem das peças de cada galeria
- `img/galeria/`, `img/capas/` — imagens
- `capas.js` — capa de cada projeto
- `dash-shim.js` — carrega os dados locais
